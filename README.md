# QRnShort

## 개요

URL2QR(프로젝트04)과 새 URL 단축 도구를 연결한 프로젝트06 정적 웹 앱입니다. 시작 화면의 **QR 코드 만들기**는 `url2qr/index.html`로, **URL 단축하기**는 `urlShort/index.html`로 이동합니다.

## 기능 명세

- QR 코드: URL 입력, 중앙 QR 생성, 클릭 시 JPG 다운로드. 프로젝트04 결과물을 `url2qr/`에 포함합니다.
- URL 단축: 입력이 비어 있으면 버튼 비활성화, 유효한 URL을 `spoo.me` OpenAPI로 단축, 읽기 전용 상자에 결과 표시.
- 복사: 결과가 있을 때만 버튼 활성화, 클립보드 복사 뒤 **복사하였습니다** 알림 표시.
- 오류 대응: 잘못된 URL, API 오류, 네트워크 실패, 12초 응답 초과를 안내합니다. URL은 단축 서비스에 전송되므로 공개 가능한 주소를 입력하세요.

## 사용 방법

`index.html`에서 도구를 선택합니다. URL 단축 페이지에서 `https://example.com`을 입력해 결과와 복사 버튼을 확인하세요. QR 코드 페이지에서는 주소를 입력하고 코드를 눌러 JPG를 내려받습니다.
